# GEO/AEO 운영 모델

## Capsule

GEO/AEO는 AI가 답을 만들 때 브랜드 콘텐츠와 평판을 이해하고 인용하기 쉽게 만드는 지속적인 마케팅 운영입니다. 브랜드 Entity, 웹사이트 구조, 답변형 콘텐츠, 외부 권위, 측정을 하나의 개선 루프로 연결합니다.

## Core

- 브랜드명, 한 줄 설명, 카테고리와 제품 관계를 일관되게 관리합니다.
- 메인·제품·솔루션·리소스 페이지를 고객 여정에 맞게 연결합니다.
- 질문에 바로 답할 구조와 인용 가능한 고유 정보·사례를 축적합니다.
- 외부 언급과 평판을 함께 관리합니다.
- AI 언급·인용, 보조 유입, 관여도와 전환을 함께 측정합니다.

## Operating Loop

`Observe → Analyze → Plan → Approve → Execute → Measure → Learn`

한 바퀴는 우선순위 질문 또는 페이지 하나를 개선하고 결과를 기록하는 것입니다.
