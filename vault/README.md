# Business OS Company Vault

이 폴더를 별도 Obsidian Vault로 엽니다. 개인 KnowledgeOS와 달리 회사 운영에 반복 사용하는 지식만 저장합니다.

```text
00_system      운영 규칙과 템플릿
10_inbox       미분류 회사 자료
20_raw         회사 원본과 증거
30_wiki        반복 사용하는 지식과 SSOT
40_navigation  Map과 탐색 문서
50_company     회사 정체성, 목표, 역할, 결정
60_sop         검증된 업무 절차
70_context     현재 업무용 압축 컨텍스트
80_outputs     보고서와 전달 산출물
90_logs        날짜별 운영 로그
99_archive     사용 종료 자료
```

실시간 리드·주문·작업 상태는 운영 DB에 저장합니다.
